From 200 thousand papers to tested claims

TiSci harvests the titanium-alloy literature, builds a knowledge graph and a table of measured values, proposes hypotheses where the graph has gaps, and tests them with DFT (MACE / VASP) and the ICME-lite chain. Every number below is read from the agent's stored records. This page is a read-only snapshot; nothing here runs a model.
